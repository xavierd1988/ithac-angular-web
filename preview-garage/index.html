Add a robot
  1. Create a new X account (a fresh email address, never used on X).
  2. On the Mac, open ITHAC-Ajouter-un-robot.command and sign in to X in the window that opens.
  3. The server tests the robot on reference accounts and puts it to work by itself. It appears here with the next free number.
